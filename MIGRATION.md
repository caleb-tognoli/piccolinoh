# Migration to the Conductor Architecture

The bot is being rebuilt around a client-side synced-embed model: the
server never touches audio, each participant's browser runs the official
YouTube IFrame Player, a small server owns the authoritative timeline,
and Discord is the control surface. This file classifies every module
in the pre-migration repo (the Phase 02 Lavalink build) so the
demolition PR has a checklist. **Delete, don't deprecate** — anything
in the delete column is removed from the working tree; git history is
the archive.

## Legend
- **keep** — reusable as-is in the new architecture.
- **adapt** — same file lives on but its content is rewritten or trimmed to drop audio/Lavalink coupling.
- **delete** — removed from the working tree in this PR. Recover from git history if ever needed.
